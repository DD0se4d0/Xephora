Política de Privacidad

En Xephora, tomamos tu privacidad en serio. Este documento detalla qué datos almacenamos y cómo los utilizamos.

Datos Almacenados

  • ID de Servidor (Guild ID): Utilizado para guardar configuraciones independientes como prefix, idioma y canales.
  • ID de Usuario (User ID): Utilizado para rastrear balances de economía, niveles, advertencias y estado AFK.
  • Configuraciones de Servidor: Mensajes personalizados, configuraciones de moneda (Caps), y roles autorizados.

Integración con Roblox

Nuestra funcionalidad de búsqueda de Roblox utiliza exclusivamente endpoints de API públicos. Nunca solicitamos contraseñas, cookies de sesión, tokens de autenticación o credenciales privadas de Roblox o de Discord.

Eliminación de Datos

Los administradores del servidor pueden restablecer la configuración del bot utilizando los comandos administrativos. Los usuarios que deseen que se elimine su información de economía o niveles pueden solicitar a un administrador que utilice el comando /economy remove.
