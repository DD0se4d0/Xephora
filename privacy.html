Privacy Policy

Effective Date: October 24, 2023

1. Data Collection

Xephora stores only the necessary data to function properly. This includes:

  • Server IDs and Channel IDs for configuration.
  • User IDs for economy balances, levels, and warnings.
  • Role IDs for permissions and level rewards.

2. Data Usage

The data is used exclusively to provide the bot's features (Economy, Levels, Moderation, etc.) within Discord. We do not sell or share your data with third parties.

3. Data Storage

All data is stored in a secure SQLite database hosted alongside the bot. No sensitive information such as passwords or tokens is ever stored or requested.

4. Roblox Integration

When using Roblox commands, Xephora fetches public data from the official Roblox API. If you link your account, only your Roblox User ID and Username are saved to provide the !myroblox functionality.

5. Data Deletion

Server administrators can reset the bot's data (Economy, Levels, Config) at any time using the respective slash commands. If the bot is removed from a server, the configuration data remains stored but becomes inactive.

6. Contact

For any privacy concerns, please join our Support Server.
