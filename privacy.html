Política de Privacidad

Describe qué datos usa Zephora y para qué, según su funcionamiento actual.

1. Qué datos procesa Zephora

Para funcionar, Zephora almacena únicamente lo necesario para sus comandos, siempre asociado a IDs técnicos de Discord (nunca a datos personales fuera de la plataforma):

DatoPara qué se usa
ID del servidor (guild)Guardar el idioma y el prefijo configurados para ese servidor.
ID del usuario de DiscordAsociar el saldo de Cap-Caps (wallet y banco) a cada usuario, por servidor.
Saldo de Cap-CapsLlevar el estado de la economía virtual y del blackjack.

2. Qué NO recolecta Zephora

  • No lee ni almacena el contenido de tus mensajes.
  • No solicita contraseñas, tokens ni credenciales de ninguna cuenta.
  • No comparte ni vende datos a terceros.
  • No procesa pagos ni datos financieros reales — Cap-Caps es una moneda virtual sin valor monetario.

3. Dónde se almacenan los datos

La configuración por servidor y los saldos de Cap-Caps se guardan de forma persistente para que no se pierdan cuando el bot se reinicia, y se identifican siempre por el ID del servidor y del usuario, nunca por nombre real ni información personal adicional.

4. Eliminación de datos

Si un administrador expulsa a Zephora de su servidor, deja de generarse actividad nueva para ese servidor. Para solicitar la eliminación de datos existentes, contactar al responsable del proyecto por los medios indicados más abajo.

5. Cambios a esta política

Esta política puede actualizarse a medida que Zephora incorpore nuevas funcionalidades. Cualquier cambio relevante en el tipo de datos procesados se reflejará aquí.

Pendiente de completar antes de publicar: datos de contacto del responsable del proyecto para solicitudes de privacidad. No se incluyen aquí porque no fueron provistos.
