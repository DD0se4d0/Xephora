Política de privacidad

Última actualización: agosto de 2026

Esta política explica qué datos recopila Xephora al operar en un servidor de Discord y cómo se utilizan. Al añadir el bot a un servidor o al usar sus comandos, aceptas los términos descritos aquí.

Datos que recopilamos

  • Identificadores de Discord: ID de usuario, ID de servidor, ID de canal y nombre de usuario, necesarios para el funcionamiento de los comandos.
  • Datos de economía: saldo de Caps, historial de transacciones, compras e inventario, por servidor.
  • Datos de niveles: XP, nivel y actividad de voz utilizada para calcular el progreso.
  • Configuración del servidor: prefijo, idioma, canales configurados, mensajes de bienvenida, AutoMessage y AutoRespond.
  • Registro de invitaciones: qué invitación trajo a cada miembro, con fines del sistema de invites.
  • Cuenta de Roblox vinculada, únicamente si el usuario la vincula de forma voluntaria con !linkroblox.

Qué no recopilamos

  • Contraseñas o credenciales de ninguna plataforma.
  • Contenido de mensajes privados fuera de los servidores donde está añadido el bot.
  • Datos de pago o información financiera real — Caps es una moneda virtual sin valor monetario.

Cómo se usan los datos

Los datos se usan exclusivamente para operar las funciones del bot: economía, niveles, bienvenidas, automatizaciones, moderación y registro de logs. Los datos de cada servidor son independientes de los demás.

Retención y eliminación

Los datos se conservan mientras Xephora permanezca en el servidor. Si el bot es expulsado, los datos del servidor pueden eliminarse tras un periodo razonable. Puedes solicitar la eliminación de tus datos personales a través del servidor de soporte.

Terceros

Al usar los comandos de Roblox, Xephora consulta información pública de la API de Roblox. Esa consulta no comparte tus datos de Discord con Roblox.

Contacto

Para dudas sobre esta política o para solicitar la eliminación de tus datos, únete al servidor de soporte.
