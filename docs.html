Documentación

Todo lo que Zephora ya sabe hacer.

Zephora es un bot de Discord multi-servidor con una economía virtual propia (Cap-Caps), un blackjack con apuestas y configuración de idioma y prefijo por servidor. Esta página documenta exactamente los comandos que existen hoy en el código — se actualiza a mano cada vez que se agrega uno nuevo, así que lo que ves acá es real.

🪙
Economía Cap-Caps

Wallet + banco por usuario, independiente en cada servidor.

🎲
Blackjack con apuestas

Partidas reales contra el dealer, con botones Hit / Stand.

🌐
Inglés y Español

Idioma configurable por servidor, persistente entre reinicios.

⚙️
Prefijo configurable

Cada servidor puede definir su propio prefijo de comandos.

Idiomas y configuración

Zephora responde en inglés o español según lo que el administrador configure para ese servidor con /xephora setup. Esa configuración, junto con el prefijo del servidor, se guarda de forma persistente y sobrevive a un reinicio del bot.

Comandos Slash — Administración

Todos viven bajo /xephora. Requieren el permiso Administrador del servidor y solo tienen versión slash — no existe alias con prefijo, para que no se confundan con los comandos normales de usuario.

/xephora ping Slash Admin

Revisa la latencia actual del bot.

Uso
/xephora ping
Permiso: Administrador
/xephora setup Slash Admin

Configura el idioma de Zephora para este servidor.

Parámetros
NombreTipoRequeridoDescripción
languageEnglish / SpanishSíIdioma que usará el bot en este servidor.
Ejemplo
/xephora setup language:Spanish
Permiso: Administrador
/xephora prefix Slash Admin

Cambia el prefijo usado por los comandos de usuario en este servidor. Por defecto es !.

Parámetros
NombreTipoRequeridoDescripción
newprefixTextoSíMáximo 5 caracteres, sin espacios.
Ejemplo
/xephora prefix newprefix:>
Permiso: Administrador
/xephora give Slash Admin

/xephora remove Slash Admin

Comandos Prefix — Economía

Disponibles para cualquier usuario del servidor, usando el prefijo configurado (! por defecto). La moneda es Cap-Caps (abreviado Caps): cada usuario tiene una wallet y un banco, y el saldo es independiente por servidor.

!caps Prefix

Muestra el saldo (wallet, banco y total) tuyo o de otro usuario.

Uso
!caps [@usuario]
Ejemplo
!caps @Usuario
Permiso: Ninguno — disponible para todos
!bank Prefix

Consulta tu cuenta bancaria, o deposita / retira Cap-Caps entre tu wallet y tu banco.

Uso
!bank balance
!bank deposit <cantidad>
!bank withdraw <cantidad>
Permiso: Ninguno — disponible para todos
!pay Prefix

Transfiere Cap-Caps desde tu wallet a la de otro usuario del mismo servidor.

Uso
!pay @usuario <cantidad>
Permiso: Ninguno — disponible para todos

Comandos Prefix — Juegos

Formas de ganar (o perder) Cap-Caps jugando.

!bj / !blackjack Prefix

Blackjack real contra el dealer, con apuesta mínima de 10 Caps. La partida se juega con botones Hit / Stand. Blackjack natural paga 1.5x, victoria normal paga 2x, empate devuelve la apuesta, y si nadie interactúa en 2 minutos la partida expira y la apuesta se devuelve automáticamente.

Uso
!bj <apuesta>
Permiso: Ninguno — disponible para todos
!work Prefix

Trabaja un turno y gana entre 100 y 200 Cap-Caps. Cooldown de 45 segundos.

Uso
!work
Permiso: Ninguno — disponible para todos
!slut Prefix

65% de probabilidad de ganar entre 200 y 300 Cap-Caps; si falla, pierdes entre el 10% y el 50% de tu wallet. Cooldown de 45 segundos.

Uso
!slut
Permiso: Ninguno — disponible para todos
!rob Prefix

Intenta robar entre 5% y 10% de la wallet de otro usuario. Hay entre 2% y 5% de probabilidad de ser atrapado, lo que te cuesta una multa del 5% al 10% de tu propia wallet. Cooldown de 60 segundos. No puedes robarte a ti mismo ni a alguien sin Caps en su wallet.

Uso
!rob @usuario
Permiso: Ninguno — disponible para todos
