Documentación

Xephora separa estrictamente los comandos. Administración usa Slash Commands (/). Usuarios usan Prefix (!).

Administración SLASH /

/xephora prefix [prefix]

Configura el prefix para comandos de usuario en el servidor.

/xephora language [idioma]

Cambia el idioma del bot (Español / English).

/economy currency set

Personaliza el singular, plural y emoji de la moneda.

/economy give @user [cantidad]

Da Caps a un usuario.

/kick @user [razón]

Expulsa a un usuario del servidor.

/ban @user [razón]

Banea a un usuario del servidor.

/logs setup #canal

Configura el canal de logs del servidor.

/welcome setup #canal

Configura el mensaje de bienvenida.

Usuario PREFIX !

!help

Muestra la lista de comandos disponibles.

!balance

Muestra tu balance de Caps.

!daily

Reclama tu recompensa diaria de Caps.

!work

Trabaja para ganar Caps.

!pay @user [cantidad]

Transfiere Caps a otro usuario.

!coinflip [cantidad]

Apuesta tus Caps lanzando una moneda.

!afk [razón]

Establece tu estado AFK global.

!roblox [usuario]

Busca información pública de un usuario de Roblox.
