Introduction

Xephora is a global, modular Discord bot designed to handle everything your community needs. From a robust virtual economy to engaging games, comprehensive moderation, and seamless automation, Xephora does it all while maintaining high performance and security.

This documentation covers the public features of the bot. Each server can configure these systems independently.

Economy

The economy system is designed to keep your server active. Each server can customize its currency name (singular and plural), emoji, and initial balances.

Currency

By default, the currency is called "Caps" (🪙). Server admins can change this to Credits, Coins, or anything else using /economy config currency.

Earning Currency

  • !daily: Claim a daily reward. Maintaining a streak gives bonus rewards.
  • !work: Work a random job with a cooldown to earn currency.
  • !pay: Transfer currency to other users.

Shop & Inventory

Admins can add items to the shop (which can grant roles) using database configurations. Users can view the shop with !shop, purchase items with !buy, and check their items with !inventory.

Games

Xephora includes a fully functional casino and betting system. All games are protected against race conditions and exploits.

Blackjack (!bj)

A realistic card game. Use the buttons to Hit, Stand, or Double down. Payouts are standard (3:2 for Blackjack).

Poker (!poker)

A simplified Texas Hold'em variant against the bot's dealer. Call to reveal the community cards and showdown.

Coinflip (!coinflip)

Bet on Heads or Tails. Simple 2x payout if you guess correctly.

Dice (!dice)

Roll a 6-sided die. Bet on High (4-6) or Low (1-3) for a 1.8x multiplier.

Slots (!slots)

Spin the reels for a chance to match 3 symbols. Jackpots (💰) offer a 10x multiplier.

Roulette (!roulette)

Bet on Red, Black, Green, or a specific number.

Horse Racing (!horse)

Bet on one of four horses and watch the race unfold in real-time via embed edits. 3x payout if your horse wins.

Levels & XP

Track user activity with a comprehensive leveling system. XP is gained by sending messages (with a cooldown) and by spending time in voice channels.

  • !level: Check your current level and XP.
  • !rank: See your server ranking position.
  • !leaderboard levels: View the top users in the server.

Admins can configure XP rates, cooldowns, and assign roles that are automatically granted when a user reaches a specific level (/levels config).

Automation

Save time with powerful automation tools that support dynamic variables and custom embeds.

Welcome System

Greet new members automatically. Configure a specific channel, custom message, and embed color.

AutoMessage

Set up recurring messages in a channel. Perfect for announcements or rules reminders. Supports multiple messages and random selection.

AutoRespond

Create custom triggers that make the bot reply automatically. Supports "exact" or "contains" matching modes.

// AutoRespond Example Trigger: hello
Response: Welcome {user} to {server}!

Roblox Integration

Look up public Roblox profiles and link your own account. Xephora never asks for passwords or sensitive data.

  • !roblox <username>: Look up a user's basic info.
  • !avatar <username>: Fetch a user's avatar thumbnail.
  • !linkroblox <username>: Link your Discord account to your Roblox profile.
  • !myroblox: View your linked Roblox profile.

Social Features

Invites

Track who invited whom. Xephora distinguishes between real invites, fake invites (bots/left users), and bonus invites.

AFK System

Set yourself as Away From Keyboard with !afk [reason]. If someone mentions you, Xephora will reply with your reason and how long you've been away. The status is removed automatically when you send a message.

Profiles

Use !profile to see a summary of a user's Discord account, balance, level, and linked Roblox account.

Moderation & Logs

Xephora provides essential slash commands for server management.

  • /kick, /ban, /timeout
  • /warn & /warnings to track user behavior.

Logging System

Keep an audit trail of everything happening in your server. Xephora can log:

  • Member join/leave, bans, timeouts, warns.
  • Message edits and deletions.
  • Channel and Role creation/deletion/updates.
  • Voice channel joins, leaves, and moves.
  • Economy transactions, Level ups, and Bot config changes.

Configuration

Xephora is fully configurable per server. Data is isolated using the guild.id, meaning configurations in one server never affect another.

  • Prefix: Change the default ! prefix.
  • Language: Switch between English and Español.
  • Modules: Enable or disable Economy, Games, Levels, etc.
  • Permissions: Use /xephora add to grant bot admin rights to trusted users without giving them Discord Administrator permissions.

Variables System

Variables can be used in Welcome messages, AutoMessages, AutoResponds, and Level-up messages. They are automatically replaced with real data.

General

{user} {username} {server} {membercount}

Economy

{balance} {currency} {currency_emoji}

Levels

{level} {xp} {rank}
